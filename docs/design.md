# GoalHub 页面与运行方案

## 目标与边界

单机开发工作台，将自然语言目标转成任务、可执行验收命令和持续开发循环。采用 Node.js 24、原生 HTTP、SQLite 与 `agent-runtime`。服务只监听本机，模型通过现有 CLI 登录使用。

## 页面设计

颜色：纸白 `#f7f9fc`、墨蓝 `#182d49`、钴蓝 `#345fea`、青绿 `#188575`、琥珀 `#aa6a10`、边框灰 `#dce3ee`。中文使用系统的 Microsoft YaHei / PingFang SC；标题采用同一字体的较粗字重，日志使用 Consolas。正文左对齐。

```text
┌ 项目导航 ┬ 目标名称 / 当前状态 / 暂停、继续 ────────────────┐
│ 新建目标 │ 规划 → 开发 → 验收 → 完成                        │
│ 项目列表 ├──────────────────────┬──────────────────────────┤
│          │ 待回答的问题          │ 定时评估 / 下次评估       │
│          │ 任务列表 / 执行记录   │ 测试结果 / Git 记录       │
│          │ 可展开的输入与输出   │ 项目运行配置               │
└──────────┴──────────────────────┴──────────────────────────┘
```

界面重心是可追踪的执行链。任务用顺序列表表现依赖，日志用时间轴展示；评估和测试作为侧栏证据，不使用无实际数据的统计卡片。移动端按目标、问题、任务、验收、记录顺序排列。

## 状态与角色

`规划中 → 执行中 → 验收中 → 已完成`。任何阶段可进入 `等待输入`、`已暂停` 或 `阻断`，继续时恢复未完成任务。等待输入保留目标、既有任务和历史；规划阶段的问题回答后重新规划，开发阶段的问题回答后继续原任务。

- 规划 Agent：生成任务、任务对应的验收项，以及必须由用户提供的问题。
- 执行 Agent：逐项开发、修复失败测试，返回结构化结果。
- 评估 Agent：每隔 X 分钟在独立 Git worktree 检查最近提交、进度和日志。只返回继续、修复、提问或完成建议。需要修复时停止当前执行轮，释放写入权后由执行 Agent 修改代码。
- 调度器：拥有状态变更权、Git 检查点和测试执行权。Agent 声称完成不会直接结束项目。

每个项目只有一个写入中的执行 Agent。评估有独立工作目录；同一项目不会重叠运行多个评估。评估间隔从一次评估开始计时，长评估结束后才安排下一次。暂停会停止所属进程树并等待退出，旧轮次不能覆盖恢复后的状态。

## 完成与恢复

每个任务完成后运行该任务的验收命令；失败自动进入修复。所有任务完成后再次执行全部验收命令，并调用最终评估。只有全部测试成功、最终评估通过、Git 提交成功才标记完成。最终评估认为仍有遗漏时，可添加明确修复任务继续执行。

普通任务和验收失败自动修复；连续三次无法启动宿主、解析协议或无法推进时记录阻断，等待用户处理外部依赖后继续。单轮 Agent 和测试都有超时。服务重启时把遗留运行改为暂停，保留 SQLite 与未提交源码，禁止自动重复未知副作用。每轮保存真实进程编号；继续前检查中断轮次的旧进程，仍存在时拒绝启动新的写入 Agent。PID 被其他进程复用时也采取保守阻断，需人工核实。

## 持久化与 Git

SQLite 使用 WAL，保存项目、任务、验收项、用户问答、Agent 轮次、流事件、Git 提交。每轮调用前保存完整提示词，结束后保存输出、会话 ID、退出状态。事件可按关键词、类型和游标查询；页面可展开每轮输入输出。显示与保存日志时遮蔽常见凭据字段。

每个项目拥有独立的 `main` 仓库，执行 Agent 在长期开发 worktree 中工作。每个任务和修复轮生成检查点并快进合并到 main；最终完成后移除开发 worktree。评估读取 main 的独立短期 worktree，结束即清理。失败和暂停保留开发目录以便恢复。

## API

`GET /api/status`，`GET/POST /api/projects`，`GET /api/projects/:id`，`POST /api/projects/:id/{start,pause,answer,evaluate}`，`GET /api/projects/:id/events`，`GET /api/runs/:id`。

写接口校验来源、JSON 类型和请求大小。静态文件使用固定映射。源码执行只面向可信本机用户；不提供公网部署或多人隔离。
