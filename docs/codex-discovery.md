# Codex 程序定位

GoalHub 的 API Key 登录、设备码登录、模型目录查询和员工执行共用 Codex 定位逻辑，不依赖从 Codex 桌面终端启动后端。

Windows 查找顺序：

1. `GOALHUB_CODEX_PATH` 明确指定的可执行文件绝对路径；配置无效时直接报错。
2. 后端 PATH 及当前用户标准 npm 安装位置，沿用共享运行模块的 npm 入口解析。
3. 当前用户 `%LOCALAPPDATA%/OpenAI/Codex/bin` 下的 Codex 桌面 CLI。多个版本选择文件更新时间最新的可用版本，每次启动重新发现，不缓存已被升级移除的路径。

其他平台保留原有 PATH 行为，也支持显式路径。不会修改系统 PATH、安装程序或切换登录方式。

找不到程序时明确提示启动失败发生在登录之前。设备码错误保留进程错误或退出码，清除一次性设备码并遮蔽凭据；模型选择器展示接口返回的实际错误，不再一律要求重新登录。

启动成功和读取模型目录不等于已完成远端推理验证；连通性测试仍以真实宿主结果为准。
