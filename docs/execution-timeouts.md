# 员工超时

所有工作统一使用执行员工的 `timeoutMinutes`，在员工配置中设置，单位为分钟，允许 1–240 分钟。全局工作沿用全局管理者 God 的员工配置。

不再提供测试、构建、预览或宿主探测的独立超时设置。历史 `testTimeoutSeconds` 和 `probeTimeoutMinutes` 不再参与执行。项目默认值仅用于兼容缺失字段的旧员工和初始化新员工，不覆盖员工已保存的超时。

每次执行读取员工配置并保留执行记录，修改后在下一次执行生效。超时、取消、非零退出或进程异常仍按失败处理。

Git、认证协议、数据库锁和进程回收的基础设施保护期限不属于员工工作超时。
