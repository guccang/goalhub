# Munder Difflin 完整办公室接入

目前使用完整上游 React / Pixi.js 办公室场景，已替换早期的简化 Canvas 房间。原地图、家具图集、角色、寻路、工位屏幕、咖啡区、休闲活动、气泡、纸条看板与消息信封均保留。

GoalHub 的宿主配置、规划确认、执行、测试、Git 和 SQLite 仍由原业务调度器负责；场景通过浏览器适配层读取真实项目状态。

使用「展开」查看大幅地图；支持拖动、滚轮缩放、全景、减少动态。点击角色查看日志；点击日历查看评估；点击看板查看任务；点击问号板处理输入；点击时钟打开项目控制。

源码位置、构建方法、固定版本、差异与授权说明见 [完整场景引擎](../office-engine/README.md)。像素素材由 [LimeZu](https://limezu.itch.io/) 创作，独立许可随仓库和页面保留。
